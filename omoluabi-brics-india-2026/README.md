# BRICS in New Delhi, 2026 — Omoluabi Investigation

Public GitHub Pages proof of concept for a map-led evidence desk covering the 18th BRICS Summit in New Delhi (12–13 September 2026).

## Structure

- `index.html` — accessible public briefing and map package.
- `SOURCE_NOTES.md` — annotated source ledger and limitations.
- `data/claims.json` — machine-readable claim-state register.
- `data/map-manifest.json` — map cards with explicit purpose, source requirements, accessibility and uncertainty rules.

## Editorial rules

- Human review decides publication status.
- A declaration is not delivery.
- Map data and map presentation remain separate.
- Inferred routes, benefits or status are never shown as observed facts.
- Every consequential map requires a nonvisual equivalent.
- Map projection, boundaries, place names, data gaps and uncertainty are disclosed.

## Current state

Published as a human-reviewed, source-led briefing. Maps 01 and 06 are the first implementation priority; they require public, versioned data before any geographic rendering is treated as evidence.
