## Scope and source status

This is a **catalog index**, not a copy or analysis of the 28 PDFs. It records the identifiers and titles listed for Release 07. The list was cross-checked against a public link register that identifies the official WAR.GOV release CSV as its source. Individual PDF contents have not been imported or reviewed for this index. Use the official portal to retrieve and verify each record.

The repository's automated PURSUE cache is still empty. Its workflow has documented that automated requests can be denied by WAR.GOV, so this page must not be read as proof that the official records are locally cached. The curated investigations elsewhere in this folder remain separate from this release catalog.
